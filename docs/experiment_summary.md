# Experiment summary

## 무엇이 성능을 만들었나

- 동일 모델의 단순 하이퍼파라미터 탐색보다 당해 시즌 상태와 경기 종류별 route 분리가
  더 큰 개선을 만들었습니다.
- 팀원 모델은 단독 점수만으로 고르지 않고 기존 모델이 틀리는 방향을 얼마나 보완하는지
  OOF에서 측정했습니다.
- 앙상블 가중치를 과거 시즌에서 동결해 미래 시즌에 그대로 적용했습니다.

## 대표 성공

| 실험 | 관찰 |
| --- | --- |
| structured 정보 비활성화 및 고정 블렌드 | 자체 기준선을 약 1003에서 1021.40으로 개선 |
| 보완적 팀원 모델 결합 | OOF 기반 가중치 0.4564로 1053.59 기록 |
| 팀 후처리 및 전문 모델 결합 | 팀 최종 최고 1104.66 기록 |

마지막 값은 팀 전체 성과이며 이 포트폴리오 작성자의 단독 구현 성과가 아닙니다.

## 대표 실패와 배운 점

### 다른 알고리즘이 곧 다른 신호는 아니다

사전학습 tabular 모델, 확률 회귀 손실 변경, 일부 피처만 사용하는 모델도 기존 챔피언과
거의 같은 방향으로 틀렸습니다. 알고리즘 이름보다 잔차 보완성을 먼저 측정해야 했습니다.

### 개발 시즌 개선은 미래 시즌 개선이 아니다

여러 후보가 2023년에는 좋아졌지만 2024년에 효과가 축소되거나 반전됐습니다.
이후 연도별 전이와 전후반 안정성을 별도 조건으로 두었습니다.

### 통계적으로 안정적이어도 효과가 너무 작을 수 있다

한 regime-gated 후보는 2024 pitcher-cluster bootstrap 개선확률이 98% 이상이었지만
사전에 정한 최소 효과 크기에 못 미쳐 승격하지 않았습니다. 방향성과 실용적 크기를
구분한 사례입니다.

## 프로젝트 운영에서 얻은 교훈

- 보고서의 계보와 실제 번들 구성이 다를 수 있으므로 SHA-256과 manifest를 정본으로 사용
- 결과 파일 경로만 믿지 않고, 어떤 anchor와 frozen weight를 사용했는지 함께 기록
- 실패한 가설의 재개 조건을 남겨 이름만 바꾼 반복 실험을 방지
- 합성 테스트 통과와 실제 추론 독립성 감사를 구분
